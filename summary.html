씨나리오 (SEA-nario) 한 장 요약 v8

FLY ASIA 해양 X AI 아이디어 해커톤 · 주제 2 · 2팀 · 팀 통합 기획안 v1.0 기준 · 자세한 내용은 전체 기획안

5줄 요약

실제 다선박 위험 장면으로 AI의 판단을 시험하고, 실패 원인과 재시험 이력을 축적하는 검증 문제은행입니다.

핵심 질문은 "한 선박을 피하는 데 성공한 AI가, 다른 선박의 위험까지 함께 낮췄는가?"입니다.

실제 AIS 시계열에서 3척 이상이 서로 영향을 주는 장면을 뽑아, 같은 조건에서 여러 회피 전략을 비교합니다.

안전성(충돌·안전영역·2차 충돌위험)을 먼저 판정하고, 판단 시점·반복 조정 같은 행동 진단과 운항 효율은 따로 분석합니다.

결과는 근거와 함께 기록해, 모델을 고친 뒤 같은 문제로 다시 시험합니다.

정리

왜 다선박인가

자율운항의 숙제(두 척 충돌회피, 항로·기상, 고장 대응, 원격운항·통신, 책임·제도) 가운데 다선박 충돌회피를 골랐습니다.

  • 조우별 항법 규칙은 두 선박 사이의 의무로 쓰여 있어, 여러 의무와 행동의 영향을 함께 적용하기 어렵습니다.
  • 하나의 회피가 다른 위험을 바꿉니다. 2017년 USS Fitzgerald는 한 척 앞을 가로지른 뒤 다른 한 척과 충돌했습니다.
  • 현장에서 흔하고 지금은 사람이 개입합니다. 도쿄만 자율운항 실증선은 한 번 항해하며 충돌회피를 107번 했고, 개발사는 혼잡할 때 사람이 개입하도록 설계했다고 밝혔습니다.
  • 검증 자료를 체계화할 필요가 있습니다. 시험 시나리오 국제표준(ISO/AWI 25927)은 개발 중이고, 사람이 만든 시나리오는 보통 100개 이하라는 연구가 있습니다.

어떻게 하나

  • 01 출제: 항적 정제·동기화 → 위험관계 추출(선박=노드, 위험관계=연결선) → 검수 → 제한된 변형. 출처·품질·가정·버전이 있는 문제 카드.
  • 02 실행·채점: 같은 초기 조건으로 전략을 비교. 주변 선박은 실제 항적 재생("타선 고정 Replay"), 자선은 시험 대상 행동대로.
  • 03 오답노트: 실패·검토 장면을 원인 가설·근거와 연결하고, 수정 후 같은 문제로 재실행.

채점

평가층 내용
안전성 충돌, 안전영역 침범, 2차 충돌위험, 항법 제약. 검증된 위반은 실패
행동 진단 회피 시점, 반복 조정, 위험 재평가, 인계. 안전 판정과 독립
운항 효율 우회 거리, 시간 증가, 감속, 항로 복귀. 안전을 만족한 결과끼리만 비교, 안전과 상쇄하지 않음

결과 상태는 통과 / 검토 필요 / 실패 / 판정 불가 네 가지입니다. 망설임(작은 변침 반복, 늦은 회피)은 자동 실패가 아니라 검토 사유로 쓰고, 전문가 검토 전 결과는 잠정 판정으로 표시합니다.

해커톤에서 보여 줄 것

실제 데이터 장면 1건 이상(자선 포함 3척 이상), 비교 전략 2종, 근거 리포트, 수정 전후 재시험. 데이터를 확보하지 못하면 "합성 데이터 개념검증"으로 표시합니다.

누가 쓰나

처음에는 자율운항 판단 알고리즘 개발·연구팀(모델 비교, 실패 재현, 회귀검증), 다음은 조선사·시험기관, 이후 운항사·선급·보험사로 넓힙니다.

한계

AIS만으로 현실 전체를 복원할 수 없고, 타선 고정 Replay는 다른 배의 반응을 재현하지 못하며, 안전영역·조종성은 가정에 기댑니다. 그래서 성능·인증을 주장하지 않고, 한 장면의 판정 근거를 설명하고 다른 사람이 같은 설정으로 재현할 수 있는지를 먼저 보여 줍니다.
